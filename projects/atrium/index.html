atrium

A lightweight messenger aggregator for macOS, Linux and Windows: all your messengers in one calm place.

Source on GitHubGPL-3.0

Atrium puts Element, Slack, Discord, WhatsApp, Teams and any other web app into one window with a compact sidebar. Every account runs in its own isolated web view, so you can stay signed in to several accounts of the same service side by side.

It is written in Rust on top of Tauri v2, with a Leptos UI, and uses the system’s web view (WebKit on macOS, WebKitGTK on Linux, WebView2 on Windows) instead of bundling its own browser engine. On macOS, with the same services open, it needs less memory and half the processes of an Electron-based aggregator. Atrium runs on macOS 14 or newer, Linux (AppImage, x86_64 and aarch64) and Windows 10 and 11; Windows support is still in progress. It is GPL-3.0-or-later licensed and updates itself.

Features

  • One window with a sidebar of accounts, unread badges and native notifications, Do Not Disturb and per-account mute.
  • Isolated sessions: each account has its own cookies, storage and caches.
  • Inactive services can sleep to free memory.
  • Links open in your browser of choice or in an app window that keeps the account’s login; sign-in popups stay in the app.
  • Per-account zoom, user agent, custom CSS, icon and camera and microphone permission.
  • Custom services, and service definitions as TOML files with an in-app editor.
  • Keyboard shortcuts, launch at login, background mode, recovery after a wake from sleep and self-updates.
  • No telemetry and no server: everything stays on your computer.

All features: Features.

Built-in services: Element / Matrix (any host), Slack, Microsoft Teams, Discord, WhatsApp, Rainbow, LinkedIn (messaging), Mastodon (any instance) and Bluesky; what Atrium counts as unread for each is on Built-in services. Anything else can be added as a custom service with a name and a URL.

Installation

Download the file for your machine from the latest release; the builds are not signed, so the first start needs one confirmation.

Platform File Install and first start
macOS 14+, Apple silicon atrium-macos-arm64.zip macOS
macOS 14+, Intel atrium-macos-x86_64.zip macOS
Linux, x86_64 atrium-linux-x86_64.AppImage (bundles its libraries) or atrium-linux-x86_64 (uses the system’s) Linux
Linux, aarch64 atrium-linux-aarch64.AppImage or atrium-linux-aarch64 Linux
Windows 10 and 11, x86_64 atrium-windows-x86_64.exe Windows

Atrium updates itself from Settings → About. The changes of every version are in the changelog.

Documentation

The wiki has the usage and settings, the service definitions, privacy and security, the known limitations and, per platform, the data locations and platform notes. To build Atrium yourself or to contribute, see DEVELOPMENT.md.
