tacit

A modern Matrix messenger focused on a polished desktop and web UX.

Source on GitLabAGPL-3.0

Tacit is a Matrix messenger with a strong focus on modern interaction patterns and a clean workflow for spaces, channels, DMs, and groups. It is a fork of Tammy and is built on top of trixnity-messenger, with the UI/UX adapted for a more focused, desktop-first experience.

Why Tacit?

  • A modern, polished desktop-first Matrix experience.
  • Faster, clearer room navigation with a contemporary chat layout.
  • Matrix power under the hood, with UX tuned for daily use.
  • A fork that focuses on delight, flow, and visual consistency.

Status

  • Target platform: Desktop / Web
  • Other platforms: Android/iOS are currently not actively tested in Tacit.
  • Releases: Unsigned desktop builds for macOS (Apple Silicon), Linux and Windows, see Download / Install. Changes are listed in CHANGELOG.tacit.md.
  • Maturity: Alpha — expect rough edges, breaking changes, and frequent iteration.

Download / Install

Download the latest release for your system:

System Download
macOS (Apple Silicon) tacit-macos-arm64.dmg
Windows (x64) tacit-windows-x64.zip
Linux (x64) tacit-linux-x64.zip

All releases and their notes are on GitLab; the files themselves are hosted on GitHub Releases.

The builds are not signed, so macOS and Windows warn you on the first start:

  • macOS: drag Tacit to Applications and open it. When macOS blocks it, click Done, then open System Settings > Privacy & Security, scroll to Security and click Open Anyway (the button only shows for about an hour after the attempt). Right-click > Open no longer works. If macOS says the app is “damaged”, run xattr -cr /Applications/Tacit.app.

    macOS asks again for every new version you download in a browser. Downloads made with curl are not flagged, so they open without the prompt:

    curl -LO https://github.com/dfuchss/tacit/releases/latest/download/tacit-macos-arm64.dmg
open tacit-macos-arm64.dmg

  • Windows: unzip and run Tacit.exe. If SmartScreen warns you, click More info > Run anyway.

  • Linux: unzip and run ./Tacit/bin/Tacit.

In-app updates

The desktop app checks GitHub for a new release about once a day (turn this off under Settings > About the app, which also has Check now). A new version is downloaded, checked against the release’s SHA256SUMS and prepared in Tacit’s data folder; your installed copy is not touched yet. Restart to update (in the banner, the settings or the tray menu) quits Tacit completely, swaps in the new version, keeps your sessions and settings, and starts it again; nothing is installed before you choose it. If the swap fails, the previous version is restored.

Tacit offers Open release page instead of updating itself when it runs from the mounted disk image (/Volumes/...), when macOS runs it from a temporary translocated copy (open it once from Applications), or when the install folder or its parent folder is not writable (e.g. C:\Program Files); update by hand in those cases.

For testing, TACIT_UPDATE_API_URL points the check at another release JSON, TACIT_UPDATE_CURRENT_VERSION pretends to be an older version, and TACIT_UPDATE_FORCE=1 checks right after start and accepts the latest release even when it is not newer.

The web version is available as a Docker image: ghcr.io/dfuchss/tacit (tags: dev for the latest development state, <version> for releases such as 26.9.2-tacit.1).

Spaces / Guilds

A matrix space is translated to the idea of guilds in Tacit. Guilds only contain rooms. All DMs and group chats are outside of guilds. Guilds can be used to organize rooms, e.g. by topic, project, or team.
